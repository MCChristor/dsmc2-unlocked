# Expander Repair

Repair notes for the DSMC2 expanders (the rear I/O modules that bolt to the brain
— Base, V-Lock, Jetpack, REDVOLT, and similar).

## Pogo-pin springs

The pogo pins that carry the expander-to-brain contacts have small internal
springs. These can break and lose contact, which shows up as an intermittent or
dead expander.

This is **repairable** (done by the author): open the pin, fit a replacement
spring of the same dimensions, and reassemble. The spring is a standard part by
size — no special component from RED is required.
